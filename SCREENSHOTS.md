# Screenshot checklist

Save each file in `public/screens/`. Missing files are hidden automatically, so add them one at a time.
Format: WebP, under 200 KB each. Web screens about 1200x750. Phone screens about 600x1200.
Use fake data only. No real names, emails, phone numbers, plates, credentials or URLs.
If a file has a different size, update `width` and `height` in `src/data.ts`.
